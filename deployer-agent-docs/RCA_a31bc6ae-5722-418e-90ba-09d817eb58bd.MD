# RCA — move-tracker-dev deploy failure (run a31bc6ae-5722-418e-90ba-09d817eb58bd)

## Verdict
SOURCE-code fault. Not a manifest/infra/secret issue. The build succeeded and the image deployed, but the backend process crashes on boot, so the K8s rollout never became ready and `deploy_k8s`/health_check timed out.

## Failed step
`deploy_k8s` — "deployment failed to become ready: timed out waiting for the condition". nginx then logged `connect() failed (111: Connection refused)` to `127.0.0.1:8001/health` because the backend had already died: `Backend died, shutting down nginx...`.

## Root cause (exact error)
```
ImportError: cannot import name 'send_driver_job_alert' from 'emails' (/app/backend/emails.py)
  File "/app/backend/server.py", line 28, in <module>
    from emails import send_booking_confirmation, send_status_update, send_driver_job_alert
```
`backend/server.py` line 28 imports **three** functions from `backend/emails.py`, but `emails.py` only defines two:
- `send_booking_confirmation` (line 131) ✅
- `send_status_update` (line 157) ✅
- `send_driver_job_alert` ❌ **missing**

The missing symbol is also actually used at `server.py` line 627:
```python
await send_driver_job_alert(u["email"], d["name"], b)
```
so simply deleting the import would break that call path — the function needs to exist. Called as `(driver_email: str, driver_name: str, booking: dict)`.

## Fix (apply in source: backend/emails.py)
Add the missing coroutine to `backend/emails.py` (it reuses the existing `_shell`, `_row`, `escape`, and `send_email` helpers already in that file, and matches the style/signature of the other two senders). Append:

```python
async def send_driver_job_alert(to: str, driver_name: str, booking: dict):
    q = booking.get("quote", {}) or {}
    total = q.get("total")
    details = (
        '<table role="presentation" width="100%" style="border-collapse:collapse;margin:16px 0">'
        + _row("Booking ref", booking.get("booking_id", ""))
        + _row("Van", booking.get("van_name", ""))
        + _row("Pickup", booking.get("pickup", ""))
        + _row("Drop-off", booking.get("dropoff", ""))
        + _row("Date & time", f'{booking.get("date", "")} at {booking.get("time", "")}')
        + _row("Distance", f'{booking.get("distance_miles", "")} miles')
        + (_row("Estimated total", f'\u00a3{total:.2f}') if isinstance(total, (int, float)) else "")
        + '</table>'
    )
    inner = (
        f'<p style="font-size:16px;color:#0f172a">Hi {escape(driver_name)},</p>'
        f'<p style="font-size:15px;color:#475569;line-height:1.6">A new job in your area is open '
        f'for bidding. Here are the details:</p>'
        f'{details}'
        f'<p style="font-size:15px;color:#475569;line-height:1.6">Sign in to your driver account '
        f'to place a bid on this job.</p>'
    )
    return await send_email(to=to,
                            subject=f'New job available \u2014 {booking.get("booking_id", "")}',
                            html=_shell(inner))
```

Alternative (only if the driver-alert feature is not wanted): remove `send_driver_job_alert` from the line-28 import AND remove/guard the call block at server.py ~line 625-629. Adding the function is preferred since the notification flow is clearly intended.
